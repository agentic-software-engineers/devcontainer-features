| Feature | Description | Image |
|---|---|---|
| **age** | A simple, modern and secure file-encryption tool. | `ghcr.io/hansehart/devcontainer-features/age` |
| **Claude Code CLI** | Anthropic's official command-line tool for agentic coding with Claude. | `ghcr.io/hansehart/devcontainer-features/claude-code` |
| **Codex CLI** | OpenAI's official command-line tool for agentic coding with Codex. | `ghcr.io/hansehart/devcontainer-features/codex` |
| **Docker (Docker in Docker)** | A rootless Docker engine for building and running containers inside the dev container. | `ghcr.io/hansehart/devcontainer-features/docker-in-docker` |
| **gh (GitHub CLI)** | GitHub's official command-line tool for issues, pull requests and releases. | `ghcr.io/hansehart/devcontainer-features/gh` |
| **glab (GitLab CLI)** | GitLab's official command-line tool for issues, merge requests and releases. | `ghcr.io/hansehart/devcontainer-features/glab` |
| **Go** | The Go programming language toolchain, with go and gofmt for building and formatting code. | `ghcr.io/hansehart/devcontainer-features/go` |
| **Headless Chrome** | A headless Chrome build for browser automation and rendering. | `ghcr.io/hansehart/devcontainer-features/headless-chrome` |
| **kind (Kubernetes in Docker)** | A tool for running local Kubernetes clusters in Docker containers, with kubectl for driving them. | `ghcr.io/hansehart/devcontainer-features/kind` |
| **LaTeX (TeX Live)** | The TeX Live distribution for typesetting LaTeX documents and bibliographies. | `ghcr.io/hansehart/devcontainer-features/latex` |
| **Node.js** | The Node.js JavaScript runtime through nvm, with node, npm and npx for running code and installing packages. | `ghcr.io/hansehart/devcontainer-features/node` |
| **OpenCode CLI** | An open-source command-line tool for agentic coding with any model provider. | `ghcr.io/hansehart/devcontainer-features/opencode` |
| **Python** | The Python programming language through uv, with python, uv and uvx for running code and managing packages. | `ghcr.io/hansehart/devcontainer-features/python` |
| **Rust** | The Rust toolchain through rustup, with rustc and cargo for building and running crates. | `ghcr.io/hansehart/devcontainer-features/rust` |
| **sops** | A tool for encrypting, editing and injecting secrets in config files. | `ghcr.io/hansehart/devcontainer-features/sops` |
| **tea (Gitea CLI)** | Gitea's official command-line tool for issues, pull requests and releases. | `ghcr.io/hansehart/devcontainer-features/tea` |
